# KlinikZakwan — Paket 2

Materi sesuai pedoman: PHP OOP, 2 tabel, tanpa Bootstrap CDN, menggunakan CSS

## Menjalankan di Laragon
1. Ekstrak folder Paket2_KlinikZakwan ke C:\laragon\www\.
2. Jalankan Apache dan MySQL.
3. Import database.sql melalui phpMyAdmin.
4. Buka http://localhost/Paket2_KlinikZakwan/ .

Database: klinikzakwan_paket2. User MySQL default Laragon: root, password kosong.

CRUD pasien tersedia (tambah, tampil, edit, hapus). Untuk paket 2-5 tersedia halaman data dokter.

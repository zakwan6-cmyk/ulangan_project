KLINIKRAZAQ - PAKET 3

Cara menjalankan:
1. Ekstrak folder KlinikZakwan_Paket3 ke C:\laragon\www\6OOP\ulangan\ (atau folder www yang diinginkan).
2. Jalankan Apache dan MySQL di Laragon.
3. Buka http://localhost/KlinikZakwan_Paket3/ (sesuaikan alamat dengan lokasi folder).
4. Database dan tabel pasien/k kunjungan akan dibuat otomatis ketika koneksi dijalankan.
   Database yang digunakan: klinikzakwan_paket3.
5. Klik Tambah Pasien untuk mengisi data. Foto jpg/jpeg/png/webp maks 3 MB.
6. Tombol detail, edit, hapus tersedia pada tabel.

Jika folder dipasang pada C:\laragon\www\6OOP\ulangan\KlinikZakwan_Paket3,
alamat browser: http://localhost/6OOP/uangan/KlinikZakwan_Paket3/ (perhatikan nama folder Anda).

Catatan: Bootstrap dan Bootstrap Icons dimuat dari CDN, jadi internet diperlukan agar ikon dan gaya Bootstrap muncul.
